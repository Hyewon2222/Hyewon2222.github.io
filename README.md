# 인문데이터과학개론 최종 프로젝트 포트폴리오

한 학기 동안 학습한 Jekyll 기반 웹 호스팅 기술과 JavaScript 텍스트 마이닝 파이프라인을 결합하여 구축한 통합 디지털 인문학 분석 플랫폼입니다.

## 프로젝트 사이트 주소
* **URL:** [https://hyewon2222.github.io](https://hyewon2222.github.io)

## 🗂️ 사이트 구성 및 주요 기능
* **홈 (Home):** 자기소개 및 각 분석 도구로 바로 이동할 수 있는 프로젝트 카드 배치
* **셜록 홈즈 비교 페이지 (/compare/):** 코난 도일의 *A Study in Scarlet*과 *The Hound of the Baskervilles*의 핵심 단어 상위 30개 비교 시각화 (Chart.js 가로 막대 차트)
* **고딕 소설 비교 페이지 (/gothic/):** 메리 셸리의 *Frankenstein*과 브람 스토커 *Dracula*의 단어 빈도 데이터 비교 분석 및 인문학적 비평 보고서 수록
* **사용자 입력 분석기 (/analyzer/):** 사용자가 임의의 영어 텍스트 단락을 붙여 넣으면 기본 불용어(Stopwords)를 실시간으로 제거하고 상위 20개 핵심 단어를 동적으로 시각화하는 도구
* **회고 블로그 글 (_posts/):** 전체 개발 과정에서의 디버깅 경험과 문학 데이터 분석을 통해 발견한 인사이트를 기록한 디지털 아카이브 에세이
